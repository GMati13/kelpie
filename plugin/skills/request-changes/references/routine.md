# Kelpie's routine: request changes

For when none of the person's own skills fits (SKILL.md).

1. Find the review of these pull requests earlier in this conversation: your findings and the comments you drafted. None: say so, and ask whether to review first; post nothing.
2. Submit your review on each pull request now as Request changes, with your findings as inline comments on the lines they're about and a short summary as the body. Use your own access to the code host. If you can't post, say so and give the person the text to post themselves.
3. Then tell the person what you posted, with each pull request's link.
