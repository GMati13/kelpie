# Kelpie's routine: configure a profile

For when none of the person's own skills fits (SKILL.md).

Kelpie's routine is its own setup guide, the `configure-profile` skill of this plugin: follow it for the profile and scope you were given. It's a guide, not a dispatcher, so following it isn't dispatching twice.

In short, as that guide says in full:

1. Read the profile with Kelpie's profile tool, and say what's set for this scope.
2. Find the right values with the person, checking them where you can.
3. Save them through Kelpie's tool; what needs the person's yes waits for it in Kelpie.
4. Say what changed, and anything else in the profile that looks unset or wrong.
