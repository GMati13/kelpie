# Kelpie's routine: explain this

For when none of the person's own skills fits (SKILL.md).

1. **Read it whole**, through your own access: a ticket with its story and subtasks; a pull request's description and its change; a file with what uses it; lines within their file and function.
2. **Find why it's there**, where that helps: the ticket it came from, the commit or pull request that added it, the comments around it.
3. **Explain it in plain words**: what it does, why it's there, and how it fits with what's around it. Short, in the person's words, with code names only where they help them find their way.
4. **Say what you couldn't read**, rather than guessing at it.
