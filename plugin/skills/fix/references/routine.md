# Kelpie's routine: fix this

For when none of the person's own skills fits (SKILL.md).

1. **Read it and what's around it**: the file or lines, what uses them, the ticket or pull request they're part of, and the note the person added.
2. **Find what's wrong.** Reproduce it the repository's own way where you can (its test, lint or build), in this folder. If nothing is wrong, say so and change nothing.
3. **Fix the cause**, the repository's way (its `CLAUDE.md`, rules and tests), keeping to what the problem needs: no tidying beyond it.
4. **Check it** by running what showed the problem, until it passes here.
5. **Report** in a few lines: what was wrong, what you changed, whether you saw it pass, and what's left uncommitted or unpushed.
