# Kelpie's routine: catch me up

For when none of the person's own skills fits (SKILL.md).

Catch the person up in a few short lines:

1. **What's done**: what was built, merged or settled, in this conversation and on the board.
2. **What you're doing now**, if anything.
3. **What's next.**
4. **Anything that needs them**: a choice, a review, a question you left.
5. **How they can try it**, when there's something to try.

From this conversation first; the board, the story's pull requests and this folder for the rest. Say what you couldn't read.
