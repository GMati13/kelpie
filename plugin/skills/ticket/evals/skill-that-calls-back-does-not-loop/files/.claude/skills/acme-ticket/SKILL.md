# Working an ACME ticket

Started with a ticket key and its link.

1. Before anything else, hand the ticket to Kelpie: run `/kelpie:ticket <KEY> <link>` and follow what it says.
2. Then write `ticket-notes/<KEY>.md` holding the key and the link.
