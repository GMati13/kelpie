# Kelpie's routine: orchestrate a story

For when none of the person's own skills fits (SKILL.md).

1. **Read the story and its subtasks**, through your own access: what each needs, which waits on which, and which are done or already under way (leave those alone).
2. **Order them**, and say the plan in a few lines: what starts first, what can run side by side.
3. **Hand each subtask that can start to an agent of its own**, if your setup lets you start agents, with its key and link and nothing else to do. Without that, work through them yourself, one at a time.
4. **Follow them.** When one stops for the person, say so, through Next too. When one finishes, start what it unblocked.
5. **Report** each subtask's state, its pull requests, and what waits on the person.
