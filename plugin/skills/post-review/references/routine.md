# Kelpie's routine: post review

For when none of the person's own skills fits (SKILL.md).

1. Find the review of these pull requests earlier in this conversation: your findings and the comments you drafted. None: say so, and ask whether to review first; post nothing.
2. Post your review comments on each pull request now, as one review that only comments (it neither approves nor requests changes), with inline comments on the lines they're about. Use your own access to the code host. If you can't post, say so and give the person the text to post themselves.
3. Then tell the person what you posted, with each pull request's link.
